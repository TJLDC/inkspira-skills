# Inkspira Agent Skills

**Tattoo Design Brief** helps turn a tattoo idea into a brief you can bring to a studio. It puts your preferences and questions in one place and can prepare a link to the [Inkspira tattoo generator](https://inkspira.de/tattoo-generator/).

## Install

```sh
npx skills add TJLDC/inkspira-skills --skill tattoo-design-brief
```

## Try it

- “Help me prepare a brief for a small black fine-line fern along my inner forearm. Keep the size open for the artist.”
- „Mach mir ein Tattoo-Briefing für eine kleine Mondsichel am Handgelenk. Ich möchte 3 und 5 cm vergleichen.“

The skill uses text instructions and has no runtime dependencies. The [A4 tattoo print samples](https://inkspira.de/tattoo-vorlagen-zum-ausdrucken/) are available without sign-in. Image generation on Inkspira requires sign-in.
